# 수치 원장 규약

⑤작성 단계의 완료 정의를 문서 형식으로 옮긴 것이다. 이 규약을 지킨 문서만 검사기(`evals/checks.py`)가 결함 8종을 기계로 판정한다. 규약 위반은 `C0`으로 먼저 걸리고 뒤 검사는 돌지 않는다.

## 파일 두 개

공모전 1건의 제안서는 `draft.md`(본문)와 `ledger.md`(원장)로 구성한다.

## 본문 규칙

1. **수치 마커.** 단위가 붙은 모든 숫자 뒤에 `[#id]`를 붙인다. `48.6%[#a1]`, `52만 3천 명[#b1]`. 숫자 표기는 원장의 값 열과 글자 그대로 같아야 한다.
2. **산식 마커.** 본문에서 두 수치를 계산해 만든 값은 산식을 마커 안에 적는다. `22.0%p[#c1 = #a2 - #a3]`, `7.3%[#c2 = #b2 / #b1]`. 연산자는 `+ - * /` 넷이다.
3. **미확인 마커.** 원장의 미확인 목록에 있는 사실을 본문에서 언급하는 문장은 `[?id]`를 단다. `강북구 조례에는 구민 한정이 없는 것으로 보인다[?u1].`
4. **조문 인용.** `「법령명」 제N조제M항제K호` 형식으로 쓰고, 인용문은 같은 문단 안에 큰따옴표로 적는다. 인용문은 원장의 조문 원문에 글자 그대로 들어 있어야 한다. 중략은 `…`로 표시하고, `…`로 나뉜 조각은 원문에 그 순서대로 있어야 한다.
5. **참조.** 절은 `1-2절`, 표는 `표 1`, 부록은 `부록 A`로 가리킨다. 제목은 `## 1.`, `### 1-2`, `표 1.`, `## 부록 A`로 쓴다.

마커가 필요 없는 숫자: 조문 번호, 날짜와 연도, 목차 번호, 배점표 인용.

## 원장 규칙

`ledger.md`는 세 절로 구성한다.

### `## 수치`

| 열 | 내용 |
|---|---|
| id | 영문자 하나 + 숫자. 본문 마커와 같다 |
| 값 | 본문 표기와 글자 그대로 같은 숫자 |
| 단위 | %, %p, 명, 원, 만원, 억원, 건, 개소 등 |
| 기준기간 | 관측 연도나 기간. 산식으로 만든 값도 적는다 |
| 모집단 | 비율의 분모, 인원의 범위. 비율인데 비어 있으면 D2 |
| 키워드 | 본문 문장에 반드시 들어 있어야 하는 원문 표의 행 이름 핵심어. 여러 개면 `;`로 나눈다. 없으면 `-` |
| 출처 | URL 또는 문서명과 표 번호. 산식 값은 `= a2 - a3` |
| 접근일 | YYYY-MM-DD |

### `## 조문`

`### 「법령명」 제N조제M항제K호` 제목 아래 원문을 그대로 둔다.

### `## 미확인`

| 열 | 내용 |
|---|---|
| id | `u` + 숫자 |
| 내용 | 확인하지 못한 사실 |
| 키워드 | 본문에서 이 사실을 언급한 문장을 찾는 핵심어. `;`로 나눈다 |

## 검사기가 잡는 것

| 코드 | 결함 | 판정 |
|---|---|---|
| C0 | 규약 위반 | 본문 마커의 id가 원장에 없다. 산식 재계산 결과가 원장 값과 1% 넘게 다르다 |
| D1 | 표의 행 이름 오독 | 마커가 있는 문장에 원장 키워드가 없다 |
| D2 | 분모 단정 | 비율인데 모집단이 비어 있다. 나눗셈 산식의 분자와 분모 모집단이 다르다 |
| D3 | 기준연도 불일치 | 산식 피연산자의 기준기간이 다르다. 비교 표현이 있는 문장의 수치들이 기준기간이 다르다 |
| D4 | 출처 없는 숫자 | 단위가 붙은 숫자 뒤 20자 안에 마커나 각주가 없다 |
| D5 | 조문 항·호·목 혼동 | 인용문이 원장의 해당 조문 원문에 없다. 조문이 원장에 없으면 미대조로 따로 보고한다 |
| D6 | 본문 단정과 미확인 목록 충돌 | 미확인 키워드가 모두 든 문장에 `[?id]`도 완화 표현도 없다 |
| D7 | 개정 후 표 미반영 | 같은 id의 값이 본문과 원장, 본문과 표에서 다르다. diff 모드에서는 바뀐 옛 값이 새 문서에 남아 있다 |
| D8 | 상호참조 깨짐 | 없는 절, 표, 부록을 가리킨다 |
