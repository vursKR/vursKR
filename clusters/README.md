# clusters/

건별 디렉토리 밖에 두는 재사용 자산. 재사용이 목적이다(wayfinder 맵 결정, 이슈 #8).

디렉토리 이름은 발주처 클러스터 단위: `<클러스터-슬러그>/`. 1차 클러스터는 착수 보고서(`docs/plan/kickoff-report.md`)가 정한 중앙부처 HR·고용·데이터·AI 계열이다. 예: `moel/`(고용노동부), `mois/`(행정안전부).

## 디렉토리 안의 파일

| 파일 | 내용 |
|---|---|
| `agencies.md` | 이 클러스터에 속한 발주처의 기존사업 인벤토리(③정찰이 누적) |
| `winners.md` | 과거 수상작 사례 라이브러리 |
| `checklist.md` | 이 클러스터에서 실제로 발생한 오류 체크리스트(⑧학습이 갱신) |

강남구처럼 이미 130개 인벤토리가 있는 자치구는 `seoul-gangnam/`으로 별도 클러스터를 둔다.
